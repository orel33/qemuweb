Commandes QEMU : QemuNet historique et démo web

Commande fournie par Orel · VM « grave » · Debian 10 · une option par ligne logique

qemu-system-x86_64 \
Option de la commande historiqueFonction / remarque
-name grave \Nom de la VM dans QEMU ; ne change pas le hostname de l’invité.
-rtc base=localtime \Initialise l’horloge matérielle virtuelle à l’heure locale.
-k fr \Disposition du clavier pour l’entrée graphique QEMU.
-M accel=kvm \Accélération KVM ; modèle de machine laissé au défaut de QEMU.
-m 200 \200 Mio de mémoire vive.
-drive file=/tmp/qemunet-orel-aSZ1nL/grave.qcow2,format=qcow2,index=0,media=disk \Disque QCOW2 de la VM ; index 0. Aucun bus n’est explicitement précisé.
-fsdev local,id=share0,path=/tmp/qemunet-orel-aSZ1nL/grave,security_model=mapped \Déclare le répertoire partagé côté hôte et son modèle de permissions.
-device virtio-9p-pci,fsdev=share0,mount_tag=host \Expose ce répertoire à l’invité via virtio-9p, sous le tag « host ».
-netdev vde,sock=/tmp/qemunet-orel-aSZ1nL/switch/s1,port=4,id=s1 \Connecte la VM au port 4 du switch VDE « s1 ».
-device e1000,netdev=s1,mac=AA:AA:AA:AA:03:00 \Carte réseau e1000 liée à s1 ; adresse MAC fixée.
-kernel /home/orel/Documents/projet-qemunet/qemunet/images/debian10.vmlinuz \Charge directement ce noyau Linux, sans passer par le chargeur du disque.
-initrd /home/orel/Documents/projet-qemunet/qemunet/images/debian10.initrd \Charge l’initrd correspondant au noyau.
-append 'root=/dev/sda1 rw net.ifnames=0 console=ttyS0 console=tty0 user=orel ' \Paramètres du noyau : racine, écriture, noms réseau, consoles et paramètre invité « user ».
-pidfile /tmp/qemunet-orel-aSZ1nL/grave.pidEnregistre le PID du processus QEMU dans un fichier.

Démo web actuelle : lancement type de Debian 13

Exemple KVM · PID et SESSION varient selon l’instance · les chemins sont absolus en exécution

qemu-system-x86_64 \
Option construite par server.jsFonction / remarque
-machine q35 \Choisit explicitement le modèle de machine q35.
-accel kvm \KVM si disponible ; TCG lorsque choisi ou nécessaire.
-m 1024 \1024 Mio pour l’image Debian 13.
-smp 1 \Un processeur virtuel.
-display none \Pas de fenêtre graphique QEMU ; interface dans le navigateur.
-monitor unix:/home/orel/Documents/projet-qemunet/qemuweb/runtime/qemuweb-PID-SESSION.monitor.sock,server=on,wait=off \Socket de contrôle QEMU utilisé par le serveur.
-chardev socket,id=serial0,path=/home/orel/Documents/projet-qemunet/qemuweb/runtime/qemuweb-PID-SESSION.sock,server=on,wait=off \Socket recevant les données de la console série virtuelle.
-serial chardev:serial0 \Branche le port série de la VM au socket relayé vers xterm.js.
-drive file=/home/orel/Documents/projet-qemunet/qemuweb/runtime/qemuweb-PID-SESSION-debian13-overlay.qcow2,if=virtio,format=qcow2,media=disk \Disque différentiel QCOW2 sur bus virtio ; « disk » explicite ; base RAW préparée.
-boot order=c \Démarre sur le disque, qui charge son propre noyau.
-nic user,restrict=onRéseau QEMU en mode utilisateur restreint ; pas de switch VDE.

Avant ce lancement, qemu-img create -f qcow2 -F raw -b images/debian-13-qemunet-v2-amd64.raw runtime/qemuweb-PID-SESSION-debian13-overlay.qcow2 crée le différentiel. La console ttyS0 et les comptes ont été configurés à l’avance dans la base RAW par prepare.sh.

Synthèse comparative

Options équivalentes ou liées placées sur une même ligne.

Commande historiqueDémo webDifférence pratique
-M accel=kvm-machine q35 -accel kvmKVM dans les deux ; q35 fixé dans la démo, TCG possible.
-m 200-m 1024 -smp 1Mémoire différente ; CPU explicite dans la démo.
-drive …grave.qcow2,media=disk-drive …overlay.qcow2,if=virtio,media=diskQCOW2 et support disque dans les deux ; différentiel sur RAW et bus virtio dans la démo.
-kernel -initrd -append-boot order=cNoyau et paramètres fournis au lancement contre démarrage autonome du disque préparé.
console=ttyS0 dans -append-serial chardev:serial0Le premier dirige le noyau vers le port série ; le second relie ce port à l’hôte. Dans la démo, ttyS0 est configuré dans l’image.
-netdev vde + -device e1000-nic user,restrict=onSwitch VDE, port et MAC fixés contre réseau utilisateur QEMU.
-fsdev + virtio-9p-pci—Partage de dossier présent seulement dans la commande historique.
-pidfile-monitor unix:…PID écrit dans un fichier contre pilotage par Node et socket moniteur.
-k fr -rtc base=localtime-display noneClavier graphique et horloge locale contre console web et RTC UTC par défaut.

Point central : l’ancien QemuNet force le noyau et sa console au lancement. La démo web prépare le système hors ligne, puis relie sa console série au navigateur lors de l’exécution.

Sources : commandes fournies par Orel et server.js du projet qemuweb ; documentation QEMU : qemu.org/docs/master/system/qemu-manpage.html et qemu.org/docs/master/system/linuxboot.html.
