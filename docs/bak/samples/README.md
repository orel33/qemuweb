# JSON examples

The four JSON files in this directory illustrate the schemas accepted by QemuWeb: `config.json` schema 4, `session.json` schema 4, `host.json` schema 3 and `switch.json` schema 2. They are referenced by `docs/manual.md`.

Subdirectories named `proposal` or `proposal-new` are historical working drafts and are not part of the accepted format.
